# Meu Portfólio

Portfólio Profissional

NextJs TypeScript Tailwind

# Sobre o projeto

Este é o código-fonte do meu portfólio, desenvolvido com NextJs, TypeScript e Tailwind, destacando meus projetos, minhas habilidades e contato form para me contactar. O site é moderno, responsivo e com animações fluidas para proporcionar uma boa experiência ao visitante.

# Link do Projeto

Código no ar: https://portifolio-wje3.vercel.app/

# Tecnologias utilizadas

## Frontend

NextJs
TypeScript
Tailwind

## Animações & Estilo

motion
aos
swiper

## Funcionalidades

EmailJS (envio de e-mails)
react-toastify (notificações)

# Como executar

## Front end web

Pré-requisitos: npm

```bash
# clonar repositório

git clone https://github.com/Ernest60/portifolio.git

# entrar na pasta do projeto portifolio
cd portifolio


# Instale as dependências:
npm install

# executar o projeto
npm run dev

Open (http://localhost:3000) with your browser to see the result.


```
